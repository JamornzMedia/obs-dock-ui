# OBSScore Dock UI v2.9.5.8

อัปเดตวันที่ 29 ตุลาคม 2569 · รวมทุกอย่างที่เปลี่ยนตั้งแต่ v2.9.5.5 (รวม 2.9.5.6 Hotfix และ 2.9.5.7)

## ✨ ไฮไลต์

### Action อัตโนมัติตอนนับถอยหลัง + สั่ง PlayScore

- ปุ่ม Action ตั้งค่า "อัตโนมัติ: เหลือกี่วินาที" ได้ เมื่อนับถอยหลังถึงเวลานั้น ปุ่มจะทำงานเอง เช่น ปิด Group ตอนเหลือ 10 วินาที
- เพิ่มประเภท Action `PlayScore`: Show, Hide หรือ Toggle และเลือกชื่อกราฟิกได้
- ปุ่มที่ตั้งเวลาไว้จะแสดงวินาทีบนปุ่ม

### หน้าทีม + คะแนนแบบใหม่ (Match Board)

- โลโก้ ชื่อทีม และคะแนนหลัก รวมอยู่ในการ์ดเดียวของแต่ละทีม สีการ์ดตามสีทีม (รวมสีเสื้อเอี้ยม)
- ปุ่ม **+** สูงอยู่ด้านบน ปุ่ม **−** เล็กอยู่ด้านล่าง กดง่ายขึ้นตอนไลฟ์
- ปุ่ม ⚙️ มุมขวาบนของการ์ด ใช้ตั้งสีหลัก สีรอง และเปิดสีเสื้อเอี้ยม
- ปุ่มสลับฝั่ง / ย้อนกลับ / รีเซ็ตคะแนน เป็นปุ่มเล็กอยู่ตรงกลางระหว่างสองทีม
- สีรองแสดงเป็นแถบบน/ล่างของการ์ด ตัว VS ใหญ่และชัดขึ้น

### 👕 ลายเสื้อ 19 แบบ

เลือกลายเสื้อของแต่ละทีมได้ในหน้าต่าง ⚙️ เช่น ลายทางตั้ง ลายขวาง แถบเฉียง ครึ่งซีก ตาราง บั้ง V ลายพราง ฯลฯ ลายใช้สีรองของทีม และระบบจำไว้ตามชื่อทีม

### 🎱 กราฟิกสนุกเกอร์ (ใหม่)

- เลือก **Snooker** ในหน้าตั้งค่ากราฟิกกีฬา (Sport Graphics Settings)
- มีปุ่มลูก 1–7, ฟาวล์ +4 ถึง +7, นับเบรก, เบรกสูงสุด, แดงที่เหลือ และแต้มที่เหลือบนโต๊ะ
- กดจบเฟรมได้ (แต้มในเฟรม = คะแนนหลัก, เฟรมที่ชนะ = คะแนนรอง)
- กราฟิกใน OBS ใช้ Browser Source `Snooker_Main_Score` (ไฟล์ `snooker_score.html` ขนาด 1280×160) ปรับสีและการแสดงผลได้ทั้งหมด

### 🎨 ธีม Sport ใหม่ + รองรับ Dock แคบ

- หน้าตาแบบงานถ่ายทอดกีฬา สลับกลับแบบเดิมได้ที่ **ตั้งค่า → แสดงผล → ธีม**
- บีบ Dock ให้แคบมากแค่ไหน ปุ่มก็ไม่ตกบรรทัดหรือล้นขอบ

### 🖼️ โลโก้ทีมจาก jamornz.com แสดงใน OBS ได้เลย

- เมื่อเชื่อมต่อ jamornz.com, Dock จะเก็บโลโก้ทุกทีม (รวมโลโก้ที่ทีมอัปโหลดผ่านพอร์ทัล) ไว้ในเครื่อง ใช้ได้แม้ออฟไลน์
- แสดงใน OBS ผ่าน Browser Source `logo_team_a_web` / `logo_team_b_web`
- สร้าง Source ได้ในคลิกเดียว ที่หน้าตั้งค่า jamornz.com หรือหน้าต่างโลโก้ (วางตำแหน่งและขนาดเท่า Image Source เดิม แล้วซ่อนตัวเดิมให้ ไม่ลบ)

### 🔐 บัญชีผู้ใช้มีรหัส 4 หลัก

- ชื่อผู้ใช้ป้องกันด้วยรหัส 4 หลัก เข้าจากเครื่องไหนก็ได้ แม้ล้างแคชไปแล้ว
- ผู้ใช้เดิมที่ยังไม่มีรหัส จะได้ตั้งรหัสตอนเข้าใช้งานครั้งแรก
- ใส่รหัสผิด 5 ครั้ง ต้องรอ 1 นาที

### ❤️ สั่ง PlayGroup จากปุ่ม Action

- ปุ่ม Action มีประเภทใหม่ **PlayGroup** สั่ง Show / Hide / Toggle ไปที่ Group ❤️ ของ PlayGroup ตามชื่อ
- ช่องชื่อ Group มีรายชื่อให้เลือกอัตโนมัติ (ใส่ชื่อจะมีหรือไม่มี ❤️ ก็ได้)
- ต้องติดตั้งปลั๊กอิน [PlayGroup](https://github.com/JamornzMedia/PlayGroup/releases) v1.0.0 ขึ้นไป และเชื่อมต่อ OBS WebSocket

### 🏷️ LabelAll

- รวมข้อความ Label หลายช่องเป็นข้อความเดียว ส่งเข้า Text Source ชื่อ `LabelAll` ใน OBS อัตโนมัติ
- ตั้งแพทเทิร์นเองได้ มีแท็กด่วนให้คลิกแทรก มี Preset แนะนำ และมีตัวอย่างข้อความก่อนส่งเข้า OBS
- กด **สร้าง Source ใน OBS** เพื่อสร้าง `LabelAll` ให้อัตโนมัติ

## 🔧 ปรับปรุงและแก้ไข

- **สีเสื้อเอี้ยม:** เลือกสีผ่านหน้าต่าง Popup มี 8 สีให้เลือก และเลือกสีเองได้
- **สลับฝั่งคะแนน:** ปุ่มบอกสถานะชัดเจนว่า ปกติ (A | B) หรือ สลับแล้ว (B | A)
- **รีเซ็ตทั้งหมด:** ส่งค่าเข้า OBS ทีละขั้น เวลาและครึ่งเวลาใน OBS รีเซ็ตตามแน่นอน
- ปุ่มยืนยันคะแนนแสดงเฉพาะเมื่อเลือก Tournament Manager (Local)
- ปุ่ม LabelAll เล็กลง และย้าย Tab ตั้งค่า LabelAll มาเป็นลำดับที่ 3
- **ตารางแข่ง (2.9.5.7):** เปิดไฟล์ `.csv` ได้โดยตรงจากปุ่มโหลดตาราง นอกเหนือจาก Excel (.xlsx, .xls)
- **ตารางแข่งแบบแยกสนาม (2.9.5.7):** ดึงตาราง Field 1 / Field 2 จาก Tournament Manager ได้ถูกต้อง
- **เส้นทางโลโก้ (2.9.5.7):** รองรับทั้งชื่อไฟล์อย่างเดียว (เช่น `01.png`) และเส้นทางเต็ม ไม่เกิดพาธซ้ำซ้อน
- **ความเสถียร (2.9.5.6 Hotfix):** อัปเดตโลโก้ทีละรายการ ไม่ส่งภาพเดิมซ้ำ และเว้นช่วงระหว่างภาพ ลดปัญหา OBS/NVIDIA เด้งตอนโหลด Match ID

## ⚽ Penalty Shootout v1.4

- แสดงชื่อทีม สีทีม และโลโก้จาก Dock UI อัตโนมัติ เมื่อเปิดหน้าต่างจุดโทษ
