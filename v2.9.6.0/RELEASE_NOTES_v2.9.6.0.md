# OBSScore Dock UI v2.9.6.0

อัปเดตวันที่ 12 พฤศจิกายน 2569

## ✨ ไฮไลต์

### เลือกประเภทกีฬาเพิ่ม: ฟุตบอล 11 คน / 7 คน / ฟุตซอล

- Sport Graphics Settings → เลือกประเภทกีฬา มีตัวเลือกใหม่ "Football 7 / ฟุตบอล 7 คน" และ "Futsal / ฟุตซอล"
- ฟุตบอล 7 คน และฟุตซอลใช้การตั้งค่ากราฟิกแบบฟุตบอล (กราฟิก HTML เดิมแสดงแบบฟุตบอล)

### ฟาวล์สะสมฟุตซอล ทั้ง 2 ทีม

- เลือก Futsal แล้วจะมีการ์ด "ฟาวล์สะสม" ใต้คะแนนรอง: ปุ่ม + / − ของทีม A และ B, ปุ่มรีเซ็ต
- ฟาวล์ที่ 5 เตือน "ฟาวล์ถัดไป = DFK" ฟาวล์ที่ 6 ขึ้นไปเป็นสีแดง "DIRECT FREE KICK"
- ติ๊ก "รีเซ็ตเมื่อเปลี่ยนครึ่ง" (เปิดไว้เป็นค่าเริ่มต้น) ฟาวล์จะกลับเป็น 0 เมื่อกดเปลี่ยนครึ่ง
- ส่งไปที่ PlayScore เป็น `{teamA.fouls}` `{teamB.fouls}` และ OBS Text Source ชื่อ `fouls_team_a` / `fouls_team_b` (ถ้ามี)

### ปุ่มโชว์ทดเวลา

- ข้างปุ่ม + / − ของทดเวลามีปุ่ม 📺 กดเพื่อโชว์กราฟิกทดเวลา (กราฟิกชื่อ `injury` ของ PlayScore) ได้ทุกเมื่อ
