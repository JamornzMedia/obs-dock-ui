## ✨ ไฮไลต์

### หน้าตาใหม่ "Pro"
- ออกแบบตามเกณฑ์ UI/UX Pro Max: แผงเรียบ มีชื่อส่วน (ข้อมูลแมตช์ / ทีมและคะแนน / เวลา / ปุ่ม Action / คะแนนรอง) สีเน้นเปลี่ยนตามกีฬา ตัวอักษรเล็กสุด 12px ตัดกันพอ (4.5:1 ขึ้นไป) และมีกรอบโฟกัสเมื่อใช้คีย์บอร์ด
- กรอบคะแนนหลักคงหน้าตาเดิม
- เปลี่ยนกลับได้: ตั้งค่า → Display → ธีม (Pro / Sport / Classic)

### แถบบน
- กีฬาที่ใช้อยู่ (กดเพื่อเปลี่ยน), ปุ่ม Source และปุ่มตั้งค่า ติดอยู่บนสุดตลอดเวลาเลื่อน

### เลือกกีฬา แบ่งหมวด
- ฟุตบอล: 11 คน, 7 คน, ฟุตซอล • บาสเกตบอล: บาส, 3x3 • ข้ามตาข่าย: วอลเลย์, ตะกร้อ (ใหม่), แบด, เทเบิลเทนนิส (ใหม่) • ต่อสู้: มวย • คิว: สนุกเกอร์
- แต่ละกีฬาบอกความสามารถและ Preset PlayScore ที่เข้าคู่กัน
- เพิ่มกีฬาใหม่ได้ที่ไฟล์เดียว `fcp_v2_assets/sports.js` (กีฬาใหม่ยืมระบบนับของกีฬาที่ใกล้เคียง)

### สร้าง Source แบ่งหมวด
- ทีมและคะแนน • สีและโลโก้ • เวลา • ข้อความแมตช์ • กราฟิกสำเร็จรูป (HTML) • ปลั๊กอิน (PlayScore)
- เลือกดูเฉพาะที่ใช้กับกีฬานี้ หรือทั้งหมด • บอกว่าอันไหนมีใน OBS แล้ว • สร้างทีละอัน หรือ "สร้างที่ขาดในหมวดนี้"
- เพิ่ม Source ใหม่ได้ที่ไฟล์เดียว `fcp_v2_assets/source_catalog.js`

### หน้าตาและปุ่มคะแนนตามกีฬา
- เลือกกีฬาแล้ว หน้าหลักจัดกลุ่มให้เข้ากับกีฬานั้นเอง เช่น วอลเลย์/แบด ซ่อนนาฬิกาและยกคะแนนรอง (เซต/เกม) ขึ้นมาใต้คะแนน, ฟุตซอลเอาฟาวล์สะสมไว้ใต้คะแนน, บาส 3x3 ไม่มีปุ่ม +3, ทดเวลาแสดงเฉพาะฟุตบอล
- ชื่อกลุ่มเปลี่ยนตามกีฬา เช่น "เซตที่ชนะ", "ฟาวล์ทีม", "เฟรมที่ชนะ"
- ปิดได้: จัดหน้า → เอาติ๊ก "ปรับหน้าตาตามกีฬา" ออก = ใช้หน้าเดียวกันทุกกีฬา

### จัดหน้าเอง (ปุ่มลูกศรขึ้นลงบนแถบบน)
- ทุกกลุ่มมีปุ่ม เลื่อนขึ้น / เลื่อนลง / ซ่อน-แสดง บันทึกแยกตามกีฬา และกด "ค่าเริ่มต้น" เพื่อคืนค่าได้
- แทนหน้า Customize Layout เดิม

### ออนไลน์และอันดับ (ออกแบบใหม่)
- แสดงเป็นรายการคนละแถว อ่านได้ใน Dock แคบ: อันดับ (เหรียญ 1–3), ชื่อ, ยศ, จังหวัด, เวลาใช้งาน หรือ คอม/มือถือ
- สรุปจำนวนคนออนไลน์และคนที่ใช้มือถือคุม, การ์ด "อันดับของคุณ", ช่องค้นหาชื่อหรือจังหวัด
- เต็มจอเมื่อ Dock แคบ

### ยิงจุดโทษ
- บีบ Dock แคบได้ถึงประมาณ 220px ไม่ล้นออกข้าง จุดยิงขึ้นบรรทัดใหม่ได้ ปุ่มและหน้าต่างตั้งค่าหดตามจอ
- แผงจุดโทษเต็มขอบเมื่อ Dock แคบ

### จาก v2.9.6.0
- ฟาวล์สะสมฟุตซอล 2 ทีม (ตอนนี้แสดงเมื่อเลือกฟุตซอล ไม่ต้องเปิดกราฟิก HTML)
- ปุ่มโชว์ทดเวลาใน PlayScore
